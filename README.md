# Button Mash Racer
This is starter code to be used for Module 3.  To get started, upload the starter code to 2-3 ESP32s, modifying TEAM_ID and USER_ID as indicated in the Arduino sketch.

The provided code is a competitive game in which players compete to see who can mash the buttons the fastest.

Your task is to modify the game to become a cooperative one, in which the cumulative button presses on all devices do something interesting (of your design!)
